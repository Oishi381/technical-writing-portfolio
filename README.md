## Tools and approach

- Written in Markdown and managed with Git.
- API specification written in OpenAPI 3.0 and validated with an OpenAPI validator.
- Code samples were run and tested before publishing.
- Diagrams written in Mermaid.
- AI-assisted drafting was used for first drafts. Every sample was then reviewed, tested, and edited by me. See the authoring note at the end of each sample.
